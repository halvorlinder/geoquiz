Border data sources

The Country borders quiz is local, static study geometry. It does not request map tiles, APIs, or live geography data.

308 selected visual runs use Geoquiz’s local Natural Earth/geoBoundaries silhouette topology. Nine listed in docs/border-lines-data.md use a narrow Overture Maps Divisions 2026-08-19.0 subset derived from the OpenStreetMap planet snapshot 2026-07-23.
