# geoBoundaries microstate silhouette notices

The files beside this notice are local copies of the licence texts applicable
to the separately identified geoBoundaries 6.0 shape overrides. They apply to
the corresponding boundary data only, not to Geoquiz application code or the
Natural Earth base layer.

- `ODbL-1.0.html`: BHR, GRD, KIR, LIE, MHL, MCO, NRU, PLW, SGP, SMR, STP,
  SYC, TON, TUV, and VCT. The UI additionally credits OpenStreetMap contributors
  for the 14 OpenStreetMap/Wambacher-derived records: BHR, GRD, KIR, LIE, MHL,
  MCO, NRU, PLW, SMR, STP, SYC, TON, TUV, and VCT. Singapore's ODbL record is
  derived from its Urban Redevelopment Authority source and does not show that
  OpenStreetMap credit.
- `CC-BY-2.5.html`: BRB, DMA, KNA.
- `CC-BY-3.0-IGO.html`: FSM.
- `CC-BY-4.0.txt`: MDV.
- AND, ATG, LCA, MLT, and VAT are Public Domain according to their pinned
  geoBoundaries metadata.

Per-boundary provenance, represented year, SHA-256, source URL, licence, and
the pinned artifact URL are generated into `src/data/country-shapes.json` from
the checked local files in `scripts/vendor/geoboundaries-6.0/`.
